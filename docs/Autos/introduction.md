# Introduction to Autos

Autos are one of the most vital components of FRC programming, as a good auto equates to a good start. The autonomous period occurs for the first couple of seconds, and during that time, the robot relies heavily on program to know what to do and go.

## Auto Generators

There are many path generating tools, such as choreo, b-line, Path Planner, ect. B-line and Path Planner will be the focus, as they can be used for easy on the fly autos.

## Documentation

Path Planner documentaion can be found [here](https://pathplanner.dev/pathplannerlib.html)

B-Line documentaion can be found [here](https://bline-docs.pages.dev/)
