# Types of Branches

## Main Branch:
This is the branch that will be actively used on the robot. This branch should **not** be deleted **or** modified without mentor approval!

## Member Branches:
These branches are made by members to work on code. These branches should be deleted after a **pull request** has been submitted **and** approved.

## Event Branches:
These branches are special branches made for working on the robot at events without compromising the main branch! These branches should be created with an event flag at the start with the event code at the end! (Example: event-utwv) (UTWV being the Utah Regional)  
These branches should **not** be deleted after merging them into the main branch, in order to preserve event history!
