Contribution Rules:

  • When starting work on a repository, you must create your own branch. It is your duty to ensure that you create your own branch and that it is up to date with the main branch.

  • When working on code, please ensure that you are working on your own branch. Please do not work on the main branch or other members' branches! It is critical that everyone gets their own workspace to maximize efficiency!

  • Before you push code to your branch, please make sure that it builds in WPILib VSCode first! This will make it easier for your programming mentors to review and approve changes. (PS: Actions will also catch any build failures, but please don't resort to these as they can cost money if abused.)

  • Once you push code to your branch, make sure to decide whether to make a pull request. A pull request should be made if you were assigned to a task or your code fixes a critical issue. Pull requests can also be made if you feel that your code provides features that will make development easier. The template for pull requests can be found in the resources section!

  • Once you finish making a pull request, you should see an image like the example below! Make sure to delete your branch once it has been approved! When you want to work again, you can make a new one!
